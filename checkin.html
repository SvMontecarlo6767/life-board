    Zusammenhänge und Rückblick: Muster ansehen
    Morgens automatisch öffnen (iPhone)

    Eine Webseite merkt nicht, wann du dein Handy einschaltest – iOS bietet dafür auch keinen Auslöser. Am besten passt: Check-in öffnet sich, sobald du morgens Whoop öffnest, einmal pro Tag. So trägst du deine Stimmung ein, bevor du die Recovery siehst.

    1. Kurzbefehl „Whoop öffnen“ (für den Rückweg): Kurzbefehle → + → Aktion „App öffnen“ → Whoop → Name „Whoop öffnen“.

    2. Automation: Kurzbefehle → Automation → + → „App“ → Whoop → „Wird geöffnet“ → „Sofort ausführen“. Aktionen:

    1. „Aktuelles Datum“, dann „Datum formatieren“ → Eigenes Format yyyy-MM-dd
    2. „Datei abrufen“ aus Ordner „Kurzbefehle“, Pfad checkin.txt, „Fehler, wenn nicht gefunden“ aus
    3. „Wenn“ Datei ist nicht formatiertes Datum:
    4. → „Text“ mit dem formatierten Datum → „Datei sichern“ nach checkin.txt im Ordner „Kurzbefehle“, „Ersetzen“ an
    5. → „URLs öffnen“:
    6. „Ende Wenn“

    Damit öffnet sich der Check-in nur beim ersten Whoop-Öffnen des Tages. Nach dem Speichern bringt dich „Weiter zu Whoop“ zurück.

    Tipp: Lege den Check-in zusätzlich als Widget oder Symbol auf den Home-Bildschirm (Safari → Teilen → Zum Home-Bildschirm).
